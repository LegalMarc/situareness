# Research catalog v1

The catalog is local research data, not an ingestion contract or a runtime input. Start from `config/source-catalog.example.json` at the project root. Run `python3 skills/situareness-sources/scripts/validate_catalog.py PATH` before replacing an existing local catalog; a nonzero exit means invalid. Strict field names prevent accidental addition of private configuration, but validation cannot detect secrets embedded in permitted free-text fields or URLs: review values before sharing. Never put credentials, personal enrollment details, or precise household footprints in the catalog.

The top-level object has exactly `schema_version`, `locations`, and `sources`. Version is integer 1. Location objects have exactly `id`, `name`, `country`, and `state`. Source objects require `id`, `name`, `issuer`, `issuer_jurisdiction`, `hazard_coverage`, `authority_evidence_url`, `channel_url`, `endpoint_url`, `format`, `role`, `location_ids`, `access_status`, `runtime_support`, `enabled`, `checked_at`, `evidence_urls`, and `notes`; optional `poll_interval_seconds` and `latency_seconds` are nonnegative integers or null, with polling strictly positive if known. Null means unknown, not immediate delivery. URL fields may be null when unknown; every present URL must be HTTPS without embedded credentials or common credential-like query parameters. Evidence URLs are an array. Dates are ISO 8601 calendar dates or null. IDs are unique within each collection; referenced locations must exist. Nonempty text and coverage arrays are required; notes may be an empty string.

- `role`: `originator`, `authorized_distributor`, or `secondary`. For a distributor, authority evidence must identify the issuing authority's endorsement; the presence of a URL alone is not verification.
- `access_status`: `public_api/feed`, `enrollment_only`, `account_or_agreement_required`, `manual_only`, or `unverified`. Enrollment links are not public ingestion endpoints.
- `runtime_support`: `supported` or `proposed`. A proposal must have `enabled: false`. Only supported sources with verified public ingestion can be enabled. This validator checks structural consistency; check actual runtime adapters, evidence and channel semantics independently.

Do not delete unrelated location or source records. Do not force private or unknown fields into the strict catalog; preserve them separately in their existing local configuration. There is no automatic catalog-to-browser synchronization. A new source requires implementation and tests of a runtime adapter before being designated supported or enabled. The public example records dated research; reverify channels before relying on their current availability or capabilities.
